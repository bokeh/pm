#### Bryan

- 3.10.2rc1 published and just waiting on Panel testing
- Switching secret scanning from GitGuardian to built-in GH tool

#### Mateusz

- Redesign of sliders done and merged
  - Removed dependency on noUiSlider
  - Sleeker UI
  - Better theming support with a CSS API (classes and variables)
  - ARIA support and improved keyboard handling
- Restarted work on generalized key binding management
  - Expect to finish this by the end of the week
- Redesign `View.parent` and affect logic
  - Previously its meaning was messy, now it means just the direct parent of a view or `null` for top-level views
- Redesign of `View.ready` promise
  - Now accumulates tasks until everything is finished
  - New task scheduling API
  - Cleanup of tests, especially integration tests. No more double `await view.ready` or `defer()` and/or `paint()`
- Migrated import upkeep in Bokeh from isort to ruff
  - Removed import headers
- Improved speed of unit tests
  - Quite important for general development and quality of work with AI
- Minor fixes and improvements to bokehjs' build tools
